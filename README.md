# Sales Performance Analysis & Dashboard

## 📌 Project Overview
This project presents a comprehensive analysis of sales performance data for a retail company. The goal is to track key performance metrics, evaluate product demand, and provide actionable business insights through an interactive dashboard.

## 🛠️ Tools & Technologies Used
* **Microsoft Excel**
  * **Power Query:** For data cleaning, transformation, and ETL processes.
  * **Pivot Tables & Pivot Charts:** For data aggregation and visual analysis.
  * **Slicers & Interactive Filters:** For dynamic report exploration.
  * **Advanced Excel Functions:** `XLOOKUP`, `INDEX/MATCH`, `SUMIFS`, and Conditional Formatting.
